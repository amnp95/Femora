    SteelConcentricallyBracedFrame3D 

    SteelConcentricallyBracedFrame3D(name_prefix: str = 'steel_concentrically_braced_frame_3d', num_stories: int = 5, x_bays: Optional[Sequence[float]] = None, y_bays: Optional[Sequence[float]] = None, story_heights: Optional[Sequence[float]] = None, floor_masses: Optional[Sequence[float]] = None, brace_bays_x: Optional[Dict[str, Sequence[int]]] = None, brace_bays_y: Optional[Dict[str, Sequence[int]]] = None, brace_pattern: str = 'x', brace_area_scale: float = 1.0, target_period: Optional[float] = None, column_sections: Optional[Union[str, Sequence[str], Dict[Tuple[int, int, int], str]]] = None, beam_sections: Optional[Union[str, Sequence[str], Dict[Tuple[int, str, int, int], str]]] = None, brace_sections: Optional[Union[str, Sequence[str], Dict[Tuple[str, int, int], str]]] = None, n_ele_col: int = 1, n_ele_beam: int = 1, length_unit_system: str = 'm', origin: Tuple[float, float, float] = (0.0, 0.0, 0.0), opensees_exe: Optional[str] = None, member_formulation: str = 'force_based', integration_points: int = 5, geometric_transformation: str = 'Linear', section_factory: Optional[Callable] = None, member_options: Optional[Dict[str, dict]] = None, flange_fibers: Tuple[int, int] = (12, 4), web_fibers: Tuple[int, int] = (4, 16), element_max_iterations: int = 10, element_tolerance: float = 1e-12, brace_properties: Optional[Dict[str, float]] = None)

    Bases: Building

    Create a rectangular 3D steel frame with perimeter axial braces.

    Columns occupy every plan-grid intersection; beams connect adjacent grid points at each elevated floor. Story heights and X/Y bay widths control geometry independently. Members have six DOFs per node. The defaults are five stories, three 8 m bays in each direction, W14X90 columns, W18X35 beams, and HSS8X8X3/8 X braces in the middle perimeter bays.

    Note

    Floors and supports. Supplied floor masses are concentrated at auxiliary nodes at the rectangular plan's geometric center. The center is not calculated from member masses. No slab or shell elements are generated. Call create_rigid_diaphragms() after assembly to connect floor translations and in-plane rotation. Fixed-base constraints are also explicit: call apply_fixed_base() for a standalone building, or connect the base to a foundation in a soil-structure model.

    Material-driven fiber workflow. Pass a managed uniaxial material, G, and material_density to build(). Beams/columns automatically use force-based fiber sections; braces use the same material axially. Uniaxial Elastic stays elastic, while Steel01 can yield. AISC supplies section geometry and J; user G supplies elastic torsion GJ. Density supplies translational mass and rotational inertia independently of the constitutive law. No nD reference material or initial-tangent extraction is required. This model does not include brace buckling, local plate buckling, fracture, or fatigue. displacement_based is not currently a supported building option.

    Local axes. Local x follows the member. AISC strong-axis Ix maps to local Iy; AISC weak-axis Iy maps to local Iz. Fiber depth follows local z. Both beam directions have strong-axis vertical bending. Column_X members are strong under global X loading; Column_Y members are strong under global Y loading. Columns on the front/back grid lines use Column_X; remaining columns use Column_Y.

    Units and loads. All inputs must use one consistent unit system. length_unit_system converts AISC geometry only, not materials, masses, or loads. With m, kN, tonne, s, steel E is about 200e6 and yield stress about 345000. Floor gravity loads and member inertia are separate: create_gravity_pattern() loads supplied floor masses; material_density in build() adds member self-mass, not self-weight.

    Examples:

    Build and assemble a fixed-base elastic building:

    from femora import Model
from femora.tools.buildings import SteelConcentricallyBracedFrame3D

model = Model()
elastic = model.material.uniaxial.elastic(user_name="steel", E=200e6)
frame = SteelConcentricallyBracedFrame3D(
    num_stories=3, x_bays=[6.0, 6.0], y_bays=[8.0, 8.0],
    story_heights=[4.0, 3.5, 3.5], floor_masses=[180, 180, 150],
    column_sections=["W14X90", "W14X90", "W14X68"],
)
frame.build(model, material=elastic, G=76.923e6, material_density=7.85)
model.assembler.create_section(
    meshparts=[frame.name_prefix], num_partitions=1,
    partition_algorithm="kd-tree",
)
model.assembler.assemble(merge_points=True)
frame.apply_fixed_base(model)
frame.create_rigid_diaphragms(model)
gravity = frame.create_gravity_pattern(model, g=9.81)
model.process.add_step(gravity, "Apply floor gravity")
# Add a static analysis step to equilibrate gravity before lateral loading.

    Use Steel01 in the same fiber workflow. Override a category's material, shear modulus, or density without changing other members:

    model = Model()
steel = model.material.uniaxial.steel01(
    user_name="steel", Fy=150000, E0=200e6, b=0.01,
)
elastic_beams = model.material.uniaxial.elastic(user_name="beams", E=200e6)
frame = SteelConcentricallyBracedFrame3D(
    floor_masses=[250, 250, 250, 250, 200],
    member_options={
        "Beam_X": {"material": elastic_beams, "G": 76.923e6, "material_density": 7.85},
        "Brace": {"material_density": 7.85},
    },
)
frame.build(model, material=steel, G=76.923e6, material_density=7.85)

    Supply custom sections without changing the building layout. A factory receives keyword arguments and must return a section managed by the supplied model. It takes precedence over automatic AISC generation:

    from femora.tools.sections import aisc

def custom_section(*, model, section_name, material, category, unit_system):
    return aisc.create_section(
        section_name, model, material, type="Fiber", GJ=76.923e6 * aisc.get_section_properties(section_name, unit_system)["J"],
        unit_system=unit_system, user_name=f"{category}_{section_name}",
    )

frame = SteelConcentricallyBracedFrame3D(
    member_formulation="force_based", section_factory=custom_section,
)

    build(model, material: Material, material_density: float = 0.0, *, G: Optional[float] = None) -> CompositeMesh

    Create members and floor-mass nodes as a registered mesh part.

    Parameters:

    Name Type Description Default
    model Model

    Femora model receiving materials, sections, transformations, element definitions, and the named building mesh part.

    		 required

    CompositeMesh

    part with merge_points=True to connect coincident member ends.

    Raises:

    Type Description
    ValueError

    Note

    Call this before assembly. Supports, diaphragms, patterns, recorders, and analysis steps are separate API calls. In the uniaxial workflow, member masses and rotational inertias use AISC area/inertias, including nonlinear axial braces. Density overrides apply per category. Fiber stiffness follows the actual fiber geometry, which can differ slightly from tabulated geometry.

    Connect each floor's structural grid nodes to its auxiliary mass node.

    Parameters:

    Name Type Description Default
    model Model

    Assembled model containing this building.

    		 required
    verbose bool

    Print a floor-by-floor constraint summary; default True.

    Type Description

    create_gravity_pattern(model, g: float) -> Pattern

    Parameters:

    Name Type Description Default
    model Model

    Assembled Femora model containing the building.

    		 required
    g float

    Finite nonnegative acceleration magnitude. Zero is permitted.

    		 required

    Returns:

    Type Description
    Pattern

    Managed Plain pattern with a constant time series. Each supplied
    Pattern

    Pattern

    create_pushover_pattern(model, *, time_series: TimeSeries, base_shear: float, direction: Union[str, float] = 'x', distribution: Union[str, Sequence[float]] = 'mass_height', mode_shape: Optional[Sequence[float]] = None, eccentricity: Tuple[float, float] = (0.0, 0.0)) -> Pattern

    Name Type Description Default
    model Model

    		 required
    time_series TimeSeries

    Mandatory time series managed by this model. Use a linear series for conventional displacement-controlled pushover. A constant series does not supply an adjustable load factor.

    		 required
    base_shear float

    Positive reference total horizontal force, in the model's force units, before time-series scaling.

    		 required
    direction Union[str, float]

    "x", "y", or degrees counterclockwise from global X toward Y. Use 180 or 270 for the negative directions.

    		 'x'
    distribution Union[str, Sequence[float]]

    "mass" (alias "uniform"), "mass_height" (alias "triangular"), "modal", or one nonnegative relative force weight per floor. Mass-based patterns use the supplied floor_masses, excluding member self-mass. Heights are measured above the building base.

    		 'mass_height'
    mode_shape Optional[Sequence[float]]

    For "modal" only, one horizontal modal amplitude per floor, already projected onto the loading direction. Forces are proportional to mass times amplitude. Signed profiles are supported unless their net resultant is zero. No solver is launched and no mode is selected automatically.

    		 None
    eccentricity Tuple[float, float]

    Pattern

    Pattern

    Pattern

    factor; this is a net signed resultant for modal distributions.

    Type Description
    ValueError

    Inputs are invalid, floor nodes are missing or ambiguous, or rigid diaphragms have not been created.

    material Optional[Union[Dict[str, object], Callable]]

    		 None

This is separate from the material object because member mass is a building-generation calculation, while rho on the material is an OpenSees material parameter.     Dict[str, ndarray]

    Dictionary with frequencies, periods, node_tags,
    Dict[str, ndarray]

    Dict[str, ndarray]

    Dict[str, ndarray]

    Type Description
    ValueError

    Note
